# p0 — Research Incubator

A structured holding space for technical ideas, architectural patterns, and
domain topics that are not yet ready to become portfolio projects.

The incubator serves three purposes:

1. **Capture** — record an idea with enough context that it does not need to
   be reconstructed later.
2. **Research** — accumulate evidence and open questions until a decision is
   possible.
3. **Place or park** — either move the topic into a real project (with a
   traceable record of why and where) or explicitly park it with a stated
   condition for revisiting.

---

## How to use

- Add a new file under `topics/` using `TEMPLATE.md`.
- Update `INDEX.md` whenever a topic's status changes.
- A topic is **placed** when it lands in a project: link to the commit or PR.
- A topic is **parked** when a deliberate decision is made not to pursue it
  now: record the reason and the condition that would reopen it.

## Status definitions

| Status | Meaning |
|--------|---------|
| `raw` | Idea noted, minimal research done |
| `researched` | Explored enough to make a decision |
| `placed` | Moved into a real project |
| `parked` | Deliberately deferred — condition for revisit recorded |
